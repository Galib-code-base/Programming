Expressions are a sequence of operants and operators that reduses to a sinngle value.

    eg.
        sum = 5 + 3

C operatores are of various categories,
    1. Arithmetic operators
        eg.
            +, -, *, /, %
    2. Relational operators
        eg.
            ==, !=, >, <, >=, <=
    3. Logical operators
        eg.
            &&, ||, !
    4. Assignment operators
        eg.
            =, +=, -=, *=, /=, %=, <<=, >>=, &=, |=, ^=
    5. Increment or Decrement operators
        eg.
            ++, --
    6. Conditional/Ternary operators
        eg.
            ?, :, ;
            condition_to_chk ? expretion1 (True) : expretion2 (False);
    7. Bitwise Operators
        eg.
            & (AND), | (OR), ^ (XOR), ~ (One's Complement), << (Left shift), >> (Right shift)
